PostgreSQL 12 was released on 2019-10-03. A dump/restore using pg_dumpall or use of pg_upgrade or logical replication is required for those wishing to migrate data from any previous release. Version 12 contains a number of changes that may affect compatibility with previous releases.
Move recovery.conf settings into postgresql.conf. recovery.conf is no longer used, and the server will not start if that file exists. recovery.signal and standby.signal files are now used to switch into non-primary mode. The trigger_file setting has been renamed to promote_trigger_file. The standby_mode setting has been removed.
Do not allow multiple conflicting recovery_target settings. Specifically, only allow one of recovery_target, recovery_target_lsn, recovery_target_name, recovery_target_time, and recovery_target_xid to be specified.
Cause recovery to advance to the latest timeline by default. Specifically, recovery_target_timeline now defaults to latest. Previously, it defaulted to current.
